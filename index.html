Notes

Short write-ups of problems I ran into and how I solved them.

Moving two apps to a new Azure subscription

Both UTown apps had to move from a student subscription to the residence’s own. Azure refused to create a PostgreSQL server in Southeast Asia on the new subscription, at any size, so the database now runs in Hong Kong. That adds about 30 ms per query, which neither app notices. Deploys use GitHub’s OIDC login, and Azure trusts only the main branch of the two repos, so there is no deploy password to leak. Both apps scale to zero when idle, which keeps the bill around US$25–35 a month.

Azure Container Apps, PostgreSQL 17, Entra ID, GitHub Actions

Stopping two people from booking the last slot

Checking whether a kitchen slot is full and then inserting a booking leaves a gap where two requests can both pass the check. UTR Kitchen takes a PostgreSQL advisory lock on the date and slot inside the booking transaction, so the count and the insert happen together. In a test with eight simultaneous requests for one remaining place, exactly one succeeds.

PostgreSQL, Drizzle, Express

Pi-hole broke the TV

After I moved my home network’s DNS to Pi-hole, Singtel TV stopped working. Sending the TV’s lookups to Singtel’s own DNS servers, while everything else stayed on Pi-hole, brought it back.

Pi-hole, DNS, DHCP
